# 🔥 Huorong Internet Security — Пользовательские настройки

> Набор проверенных настроек HIPS и Firewall для бесплатного антивируса **Huorong Internet Security v6** (火绒安全).

## 🛡️ HIPS — Пользовательские правила

### Что блокируют правила

**Группа 1 — Блокировка LOLBins (Living Off the Land)**  
Запрещает системным утилитам Windows запускать опасные дочерние процессы — один из самых популярных способов обхода антивирусов вирусами, шифровальщиками и бесфайловыми угрозами:

| Процесс | Что заблокировано |
|---|---|
| `explorer.exe` | mshta, cmd, powershell, cscript, wscript |
| `mshta.exe` (x86/x64) | Все дочерние процессы |
| `regsvr32.exe` (x86/x64) | mshta, powershell, cmd, cscript, wscript |
| `rundll32.exe` (x86/x64) | mshta, powershell, cmd, cscript, wscript |
| `powershell.exe` (x86/x64) | Все дочерние процессы |
| `cscript.exe` (x86/x64) | Все дочерние процессы |
| `wscript.exe` (x86/x64) | Все дочерние процессы |
| `msiexec.exe` (x86/x64) | Все дочерние процессы |
| `wmic.exe` (x86/x64) | Все дочерние процессы |
| `certutil.exe` (x86/x64) | Все дочерние процессы |
| `bitsadmin.exe` (x86/x64) | Все дочерние процессы |
| `csc.exe` — компилятор .NET (x86/x64) | Все дочерние процессы |
| `jsc.exe` — JS-компилятор .NET (x86/x64) | Все дочерние процессы |

**Группа 2 — Защита системных файлов**  
Запрет изменения `userinit.exe` и `taskmgr.exe` любым процессом.

**Группа 3 — Защита реестра**  
Блокировка изменений критических веток:
- Ключи автозапуска (`Run`, `RunOnce`) — HKLM, HKCU, HKU
- Ключи `Winlogon` — Shell, Userinit, System
- `AppInit_DLLs` — защита от DLL-инъекций
- `Image File Execution Options` — защита от подмены отладчика
- Путь к файлу `hosts` — защита от перенаправления DNS
- Политики системы и проводника
- Загрузчик HDD (`\Device\Harddisk0\DR0`) — защита MBR

## ⚙️ Как импортировать правила HIPS

1. Скачайте файл `HIPS_Custom_Rules.json` из этого репозитория
2. Откройте **Huorong Internet Security**
3. Перейдите в **HIPS** → **Custom Rules**
4. Нажмите **Импорт** и выберите скачанный файл
5. Готово — правила активны немедленно

> ⚠️ **Важно:** все правила работают в режиме «Блокировать + Записывать в лог». Если какая-то легитимная программа перестала запускаться — проверьте лог HIPS и добавьте исключение.
