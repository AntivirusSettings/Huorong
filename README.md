# Huorong
Настройки бесплатного антивируса Huorong Internet Security

Набор проверенных и оптимизированных настроек для бесплатного антивируса Huorong Internet Security v6

Цель проекта — максимально повысить уровень защиты Windows, при этом сохранив высокую скорость работы системы и минимальное количество ложных срабатываний.
